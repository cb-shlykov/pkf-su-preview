2. Какую информацию собирает Сайт

2.1. Информация, которую пользователь предоставляет самостоятельно — при заполнении форм заявки на Сайте: имя, номер телефона, комментарий к заявке (необязательное поле). Обработка этих данных осуществляется в соответствии с Политикой обработки персональных данных, с которой пользователь соглашается при отправке формы.

2.2. Информация, собираемая автоматически при посещении Сайта:

  • технические данные (IP-адрес, тип и версия браузера, тип устройства, операционная система);
  • данные о взаимодействии с Сайтом (посещённые страницы, время на сайте, источник перехода) — собираются с помощью сервиса Яндекс.Метрика;
  • файлы cookie — см. раздел 5.

3. Цели обработки информации

  • обработка и выполнение заявок, поступивших через формы Сайта;
  • обратная связь с пользователем по вопросам, связанным с заявкой (уточнение параметров заказа, расчёт стоимости, консультация);
  • улучшение работы Сайта, анализ посещаемости и поведения пользователей для повышения удобства использования;
  • защита форм Сайта от автоматических (бот) обращений с помощью сервиса Яндекс.SmartCaptcha.

4. Передача информации третьим лицам

Оператор не передаёт персональные данные пользователей третьим лицам, за исключением случаев:

  • использования сервисов Яндекса, встроенных в Сайт: Яндекс.Карты (отображение карты с адресом производства), Яндекс.SmartCaptcha (защита форм от спама), Яндекс.Метрика (статистика посещений). Эти сервисы могут получать техническую информацию о браузере и устройстве пользователя в объёме, необходимом для их работы, в соответствии с политиками конфиденциальности ООО «Яндекс»;
  • если это прямо предусмотрено законодательством РФ (по запросу уполномоченных государственных органов).

Обработка информации осуществляется на территории Российской Федерации. Трансграничная передача данных не осуществляется.
